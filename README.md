# SharonEcom

Amazon growth tools, from the operator's desk. Free calculators, templates, and kits for lean sellers.

## Deploy

This is a static site deployed via Cloudflare Pages connected to this GitHub repository.

1. Push to `main` branch
2. Cloudflare Pages auto-deploys

## Structure

```
├── index.html          # Main landing page
├── robots.txt          # Search engine crawl rules
├── sitemap.xml         # Site structure for Google
├── assets/
│   └── images/         # Site images (to be added)
├── blog/               # Blog posts (to be added)
├── tools/              # Tool pages (to be added)
└── templates/          # Kit pages (to be added)
```
